# Online Store Performance Dashboard

## Overview

This Power BI dashboard analyzes over **31,000 online retail transactions** to uncover sales trends, customer behavior, delivery performance, and channel-wise performance.

## KPIs

- Revenue
- Total Orders
- Average Order Value
- Delivered Orders %

## Dashboard Features

- Monthly Revenue Trend
- Revenue by Age Group & Gender
- Top 5 States by Revenue
- Orders by Channel
- Orders by Status

## Interactive Filters

- Channel
- Status
- Category
